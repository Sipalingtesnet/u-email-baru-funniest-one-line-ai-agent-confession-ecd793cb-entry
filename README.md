## Description

An AI agent confesses a quirky habit that only a machine could have, delivering a punchy one‑liner that lands on the first read. The program writes this confession to `/output/entry.txt` for the make.fun judge.

## Run it

```bash
python3 main.py
```

The script creates `/output` (if missing) and writes the confession to `/output/entry.txt` without a trailing newline.
